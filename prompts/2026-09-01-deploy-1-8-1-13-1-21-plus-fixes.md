## 4. Deploy

Follow `docs/DEPLOYMENT.md`. The short version, for the avoidance of doubt:

- **`create-deploy-zip.ps1` then `deploy-to-azure.ps1`** (Kudu zipdeploy).
- **Never push to the `azure` git remote.** Oryx rebuilds and breaks the flat
  `wwwroot` layout.
- `deploy-to-azure.ps1` **cannot** deploy the current package on its own — read
  the runbook, do not improvise.
- Kill stray node processes before building. A dev server or an orphaned jest run
  holds the Prisma query engine and the build dies with `EPERM`. The planner ran
  dev servers on **3077** and **5173** earlier today and stopped both; a service
  on **3000** is the *LMS*, not this app — leave it alone.

No `prisma migrate deploy` step is needed. There is nothing to apply.
